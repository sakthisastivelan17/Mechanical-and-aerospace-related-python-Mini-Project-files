# Python Practice: Aerospace & Mechanical Engineering
A collection of beginner Python scripts built around aerospace and mechanical engineering problems. Each script practices one core Python concept through a small, realistic example.

## Projects

=> | rocket_details (super keyboard).py | Inheritance, super(), constructors | A Components parent class and a Rocket child class that stores and prints Falcon 9 details |

=> | Aerospace Engine purchase app Using class methods.py | @classmethod, class variables | Tracks jet engine purchase orders for Rolls-Royce, Boeing, and Airbus |

=> | aircraft analysis in file handling-py.py | File I/O (write, read, append), loops, lists | Logs RPM, temperature, and fuel data for 5 engine tests, then reports the highest, lowest, and average of each. Also searches for an RPM value and appends a new test |

=> | mechanical mark app in file handling-py.py | File I/O, loops, lists | Saves marks for 4 mechanical subjects to a file, then calculates total, average, and highest mark |

=> | factor of safety in function -py.py | Functions, return values | Calculates Factor of Safety = ultimate strength ÷ working stress |

=> | shutdown machine codes in function -py.py | Functions, conditionals | Safety check that compares temperature and pressure against limits and returns SAFE TO OPERATE or SHUTDOWN REQUIRED |

=> | aircraft lift app in file aircraft_lift.py | input, float, arithmetic operators, print | Calculates lift on a wing from air density, velocity, wing area, and lift coefficient |

=> | aircraft speed app in file aircraft_speed.py | input, float, division, print | Calculates average speed from distance and time |

=> | aircraft travel time app in file aircraft_travel_time.py | variables, division, print | Calculates travel time from fixed distance and speed values |

=> | thrust to weight ratio app in file engine_thrust_to_engine_ratio.py | input, float, constants, division, print | Calculates an engine's thrust-to-weight ratio from thrust and mass |

=> | fuel consumption app in file fuel_consumption.py | input, float, multiplication, print | Calculates total fuel used over a flight from fuel rate and flight time |

=> | rocket acceleration app in file rocket_acceleration.py | variables, subtraction, division, print | Calculates acceleration from start and end velocity over a set time |

=> | satellite orbit speed app in file satellite_orbit_speed.py | import math, constants, math.sqrt, round, print | Calculates the circular orbital speed of a satellite around Earth |

----------------------------------------------------------------------------------------------------------------------------------------------------------------------------
## Concepts covered ##
OOP: classes, constructors, polymorphism, inheritance, super(), class methods

Functions: parameters, return values, conditional logic

File handling: writing, reading, and appending text files

Data handling: loops, lists, max(), min(), averages
